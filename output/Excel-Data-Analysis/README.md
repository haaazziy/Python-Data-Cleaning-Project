Superstore Data Analysis Using Excel

Project Overview

This project focuses on analysing Superstore sales data using Microsoft Excel. It involves data cleaning, basic calculations, Pivot Table analysis, and extracting meaningful business insights.

Project Structure

* Dataset – Original and cleaned datasets.
* Analysis – Excel workbook containing calculations and Pivot Tables.
* Screenshots – Visual evidence of the completed analysis.

Analysis Performed

* Total Sales
* Total Profit
* Average Discount
* Top 5 Products by Sales
* Top 5 Loss-Making Products
* Region-wise Sales Analysis

Tools Used

* Microsoft Excel
* Pivot Tables
* Excel Formulas
* Data Cleaning

Project Status

Basic Excel Analysis Completed.
